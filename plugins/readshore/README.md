# ReadShore

ReadShore is a read-later app. Connect your ReadShore library to find the articles, videos and posts you saved, read their saved text alongside ReadShore's summary and analysis, see what has waited longest unread, and save new links to read later.

[Connection guide](https://readshore.app/connect-ai-assistants/) · [Privacy](https://readshore.app/privacy/) · [Terms](https://readshore.app/terms/) · [Support](https://readshore.app/support/)

## Connect

Claude Code: `/plugin install readshore --marketplace flsteven87/readshore-mcp`.

Install the plugin, then sign in when your assistant opens readshore.app/connect: use the Apple Account you use in the ReadShore iPhone app and choose Allow. The remote endpoint is https://readshore.app/mcp; no API key or local server is needed. Disconnect at https://readshore.app/connect/ or in the app under Settings › Your agents.
